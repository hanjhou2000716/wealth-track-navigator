# Leveling Evaluation Methodology

職級不是單一 Title mapping。Blind evaluator 移除 Senior、Staff、Lead、Manager 等 title 字樣，改用 Scope、Complexity、Autonomy、Impact、Leadership、Cross-functional、Decision Rights、Stakeholder Scope、Business Ownership 與 Mentorship 計算。

輸出包含 `titleLevel`、`blind.level`、`confidence` 與 `titleArbitrage`。目前 API 以示範 evidence 驗證 contract；外部資料與 300+ gold corpus 尚未接入，不能宣稱外部準確度。
